## Опис проєкту

Цей репозиторій містить матеріали дипломної роботи, присвяченої розробці та експериментальному дослідженню легковагового та масштабованого пайплайну машинного навчання для автоматичного виявлення тексту, згенерованого великими мовними моделями (LLM).
